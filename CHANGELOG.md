[1.0.11] 2026-07-03 — Fixed three related "pipeline goes silent" bugs reported live during a CAPTCHA (Raghav solved it and submitted, pipeline kept waiting the full 10 minutes anyway):
(1) `_check_and_handle_captcha()`'s `still_captcha` check only tested whether the reCAPTCHA `bframe` iframe was still *attached* to the page (`"bframe" in f.url`). Google's reCAPTCHA never removes that iframe after a solve — it just hides it — so the check could never go False unless the whole page happened to hard-navigate. Replaced with a visibility check (computed `display`/`visibility`/bounding-rect) inside `page.evaluate`, with the old presence check kept as a fallback if evaluate throws.
(2) The `already_confirmed` fallback (looks for "application submitted" etc.) only read `page.body.innerText` on the top-level document, but Indeed's apply UI — including the post-submit confirmation — renders inside a nested iframe (the auto-click-Submit code a few lines down already knew this and loops `page.frames()`; the text check didn't). Now scans every frame's `document.body.innerText`, not just the top-level page.
(3) Separately: Indeed's "stop early after N consecutive 0-card searches" bail (added in 1.0.7 for the Cloudflare-block case, `INDEED_EMPTY_QUERY_BAIL_THRESHOLD`) never sent an email, unlike its sibling CAPTCHA-cooldown-exceeded stop which does. So a Cloudflare-blocked run went completely silent — no real-time alert, and since it also applied 0 jobs, `notify_session_done()`'s `if applied == 0: return False` guard suppressed the end-of-run summary too. Added a `notifier.send_alert()` call at the bail point so a blocked/Cloudflare-stopped run now emails immediately, matching the CAPTCHA-cooldown behavior. (Note: `notify_session_done`'s 0-applied suppression itself was left as-is — not touched in this change.)

## How to log a change

Before making any edit:
```bash
bash safe_update.sh start "describe what you're trying"
```

After the change works:
1. Bump `PIPELINE_VERSION` in `config.py` (e.g. 1.0.0 → 1.0.1 for a fix, → 1.1.0 for a new feature)
2. Add a line here: `## [1.0.1] YYYY-MM-DD — what changed`
3. Run `bash safe_update.sh keep` to merge and save to GitHub

If the change breaks something:
```bash
bash safe_update.sh discard   # back to last working version instantly
```
